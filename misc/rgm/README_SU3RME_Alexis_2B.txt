First, space must be specified in the file space.dat. This file contains:

Z  // Number of protons
N  // Number of neutrons
JJ // 2*J, set to -1 to include all J's
N1 // The 1st N
-1 // This indicates that all values of Sp and Sn are taken into account for the 1st N
N2 // The 2nd N
-1 // This indicates that all values of Sp and Sn are taken into account for the 2nd N

and so on.

Second, two-body densities whose RMEs are to be calculated must be specified in file tbd.dat. This file contains rows of 13 integers:

N1  N2  N3  N4  lmf  muf  SSf  lmi  mui  SSi  lm0  mu0  SS0

File tbd.dat can be generated by editing last 3 numbers in batch script generate_two_body_density_labels.sh, which are Nmax, N1vp and N1vn, where N1vp is valence N for protons and N1vn is valence N for neutrons, and submitting job by

sbatch generate_two_body_density_labels.sh

Then batch script SU3RME_Alexis_2B.sh should be edited accordingly. Then the run can be submitted by

sbatch SU3RME_Alexis_2B.sh

Output is written into file slurm-<jobID>.out.

RMEs are written into files N1_N2_N3_N4--lmf_muf_SSf--lmi_mui_SSi--irho0_lm0_mu0_SS0.suffix, where irho0=rho0-1, rho0 is outer multiplicity label for coupling (lmf,muf)x(lmi,mui)->(lm0,mu0) and suffix is pp, nn or pn for proton, neutron or proton-neutron densities, respectively.
These files contain quantum numbers of two body densities in their names and they contain rows with numbers:

ip  in  bra_max  2*Sp_bra  2*Sn_bra  2*S_bra  N_bra  lm_bra  mu_bra  jp  jn  ket_max  2*Sp_ket  2*Sn_ket  2*S_ket  N_ket  lm_ket  mu_ket
RMEs

where RMEs are indexed by irho + rhomax*j + rhomax*ket_max*i, where irho=rho-1. (0<=i<bra_max, 0<=j<ket_max)

To generate files needed to calculate seeds using get_spncci_seed_blocks, one needs to run SU3RME_Alexis_2B_digest by

sbatch SU3RME_Alexis_2B_digest.sh

These files have names N1_N2_N3_N4--lmf_muf_SSf--lmi_mui_SSi--irho0_lm0_mu0_SS0_Tz.rme, where Tz=1 for proton two-body density, Tz=-1 for neutron two-body density and Tz=0 for proton-neutron two-body density, and need to moved to folder ~/Research/thesis/spncci/get_spncci_seed_blocks_dir/lsu3shell_rme/.
