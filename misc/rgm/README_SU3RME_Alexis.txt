First, space must be specified in the file space.dat. This file contains:

Z  // Number of protons
N  // Number of neutrons
JJ // 2*J, set to -1 to include all J's
N1 // The 1st N
-1 // This indicates that all values of Sp and Sn are taken into account for the 1st N
N2 // The 2nd N
-1 // This indicates that all values of Sp and Sn are taken into account for the 2nd N

and so on.

Second, one-body densities whose RMEs are to be calculated must be specified in file obd.dat. This file contains rows of 5 integers:

N' N lambda0 mu0 2*S0

File obd.dat can be generated by editing last 3 numbers in batch script generate_one_body_unit_tensor_labels.sh, which are Nmax, N1vp and N1vn, where N1vp is valence N for protons and N1vn is valence N for neutrons, and submitting job by

sbatch generate_one_body_unit_tensor_labels.sh

Then batch script SU3RME_Alexis.sh should be edited accordingly. Then the run can be submitted by

sbatch SU3RME_Alexis.sh

Output is written into file slurm-<jobID>.out.

RMEs are written into files a+<N'>ta<N>_<lambda0>_<mu0>_<2*S0>_proton and a+<N'>ta<N>_<lambda0>_<mu0>_<2*S0>_neutron.
These files contain quantum numbers of one body densities in their names and they contain rows with numbers:

ip  in  i  2*Sp_bra  2*Sn_bra  2*S_bra  N_bra  lambda_bra  mu_bra  jp  jn  j  2*Sp_ket  2*Sn_ket  2*S_ket  N_ket  lambda_ket  mu_ket  RMEs

where RMEs are ordered according to increasing rho.

To generate files needed to calculate seeds using get_spncci_seed_blocks, one needs to run SU3RME_Alexis_digest by

sbatch SU3RME_Alexis_digest.sh

These files have names a+<N'>ta<N>_<lambda0>_<mu0>_<2*S0>_<Tz>.rme, where Tz=1 for proton one-body unit tensor and Tz=-1 for neutron one-body unit tensor, and need to moved to folder ~/Research/thesis/spncci/get_spncci_seed_blocks_dir/lsu3shell_rme/.
