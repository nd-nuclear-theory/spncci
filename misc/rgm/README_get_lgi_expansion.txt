To get the files lsu3shell_basis.dat, Brel.rme and Nrel.rme needed to calculate the expansions of LGIs in lsu3shell basis using program get_lgi_expansion we first have to run the script rununittensor01 (which imports lsu3shell_operator.py), which generates tgz files, and then the script runsu3rme01 (which imports su3rme.py), for which the tgz files are input. The tgz files for s- and p-shell nuclei for Nsigmamax up to 12 are in the project directory and therefore in su3rme.py the directory, in which the script will look fot the tgz files, is set to the project directory. This needs to be changed if we want to use the tgz files which we generated by rununittensor01.

rununittensor01 calls lsu3shell program RecoupleSU3Operator, which should be in ~/Research/code/install/haswell/lsu3shell/bin/, and spncci program generate_lsu3shell_relative_operators, which should be in ~/Research/code/spncci/programs/unit_tensors/. runsu3rme01 calls lsu3shell programs SU3RME_MPI and ncsmSU3xSU2IrrepsTabular, which should be in ~/Research/code/install/haswell/lsu3shell/bin/, and spncci programs generate_lsu3shell_model_space, which should be in ~/Research/code/spncci/programs/unit_tensors/, and get_u3s_subspaces, which should be in ~/Research/code/spncci/programs/lgi/.

runsu3rme01 generates also files with RMEs of relative 2-body unit tensors in lsu3shell basis.

See also the documentation at the beginning of get_lgi_expansion.cpp in ~/Research/code/spncci/programs/lgi/.
